# Stopwatch ⏱️

A simple and interactive **stopwatch web application** created with HTML, CSS, and JavaScript.

The project allows users to start, pause, reset, and track elapsed time.

## ⏱️ Features

- ▶️ Start timer
- ⏸️ Pause timer
- 🔄 Reset stopwatch
- 🕐 Real-time elapsed time
- 🎨 Custom interface
- ⚡ Interactive controls

## 🛠️ Built With

- HTML
- CSS
- JavaScript

## 📚 Learning Project

This project was created as a **learning project at Creator IT Academy**.

It was developed to practice JavaScript timers, event handling, time calculations, and interactive web interfaces.
